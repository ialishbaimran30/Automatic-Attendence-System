# Project memory

## Architecture and rules
Separate Django/DRF backend and React frontend. PostgreSQL is the deployment database; SQLite supports the manual local demo and fast tests. Celery/Redis runs CPU ArcFace recognition. Private encrypted biometric samples are separate from public student records. Session snapshots preserve historical rosters. Server timestamps and teacher confirmation are authoritative. Students have no auth or dashboard. Attendance never changes during enrollment or recognition.

## Decisions
Cookie session authentication with CSRF, server-enforced teacher section access, admin-only master-data management. Polling for jobs. Closed sessions form the percentage denominator; present and late count equally. Default threshold 75%, with section overrides. Capture tokens expire and are bound to user/session and single use. Independent capture groups split classifier training/validation. Similarity scores are not probabilities.
